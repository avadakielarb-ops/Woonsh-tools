# Фирмы и выписки — приложение

Локальная версия: один человек, один компьютер. Реестр фирм лежит за узким интерфейсом
(4 метода) — когда дойдёт до нескольких человек, меняется ТОЛЬКО он.

## Установка (один раз)

1. Поставь Python 3.11+ (галочку «Add to PATH» при установке).
2. Двойной клик по **`установка.bat`** — поставит библиотеки и браузер. Пару минут.
3. Двойной клик по **`запуск.bat`** — откроется окно.

Хочешь иконку на рабочем столе: **`сборка_exe.bat`** → получится
`dist\Фирмы и выписки\Фирмы и выписки.exe`.
Chromium внутрь .exe не зашивается (+300 МБ и ломается при упаковке) — при первом
запуске нажми в «Настройках» кнопку **«Установить браузер»**, это один раз.

## Как пользоваться

**Вкладка 1 «Найти фирмы».** Слово + страна + сколько → «Найти фирмы».
Пишет в `фирмы.xlsx`: лист **`13-07 ES`** (дата + страна) и лист **`Лог`** (отсев с причиной).

**Вкладка 2 «Скачать выписки».** Гео + тот же файл → «Скачать выписки».
PDF ложатся в `выписки/<ГЕО>/`, названные по фирме. В Excel дописываются
**номер в реестре** и **имя файла**. Кого не вышло — в `выписки/не_вышло.xlsx`.

**Панель «НУЖЕН ЧЕЛОВЕК»** появляется прямо в окне: капча, логин, непонятная выдача.
Делаешь шаг руками в браузере → «Продолжить». Логин запоминается на весь прогон.

## Что закрыто из найденного на прогоне

| дыра | что сделано |
|---|---|
| DnB блокирует ботов | вернул `playwright-stealth` (он был в твоём scraper.py) |
| «первая внешняя ссылка» ловила LinkedIn вместо сайта | чёрный список доменов + приоритет ссылке, подписанной «Website» |
| Excel писался в конце — падение = потеря всего | пишем и сохраняем после каждой фирмы |
| лист не знал страну — можно было качать выписки не того гео | страна в имени листа: `13-07 ES` |
| `page.pdf()` работает только в headless, а нам нужен видимый браузер | печать через CDP (`Page.printToPDF`) — работает в видимом окне |
| человек нажимал «Продолжить», не открыв карточку | перед скачиванием проверяем, что на странице есть номер фирмы |
| фирма «сгорала», даже если выписка не скачалась | бронь → подтверждение: использованной фирма становится только после PDF |

## Настройки (вкладка 3)

- чёрный список отраслей (Google Ads)
- минус-лист брендов
- «не считать сайтом» (соцсети, агрегаторы)
- правовые формы по странам

**Раз в неделю смотри лист «Лог»** — особенно причину «нет правовой формы». Это самое
частое ложное срабатывание. Что нашлось — дописывай в правовые формы.

## Первый прогон — что проверить

Запусти Часть 1 на **3 фирмах** и посмотри в браузер:
есть ли в выдаче DnB колонка **Industry**. Если её нет — чёрный список отраслей
работать не будет, и это надо чинить отдельно. Это единственный факт, который
я не смог проверить без тебя.
