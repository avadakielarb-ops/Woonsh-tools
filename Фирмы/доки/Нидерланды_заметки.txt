0. КРАТКО
------------------------------------------------------------------------------
KVK официальную выписку отдаёт ТОЛЬКО платно (€2.95 / €9.60 / €19.20).
Бесплатного PDF нет. Поэтому NL = «шаблонное» гео: данные берём с открытой
страницы поиска kvk.nl и формируем ЧЕСТНУЮ СПРАВКУ в Word (.docx).

ГРАНИЦА (не переигрывается):
- НЕ заполняем официальный бланк KVK и НЕ выдаём документ за официальную выписку
  (это подделка / выдача себя за госорган Kamer van Koophandel).
- НЕ выдумываем поля (даты акта, RSIN, капитал, акционер) → остаются прочерком «—».
- Документ честно помечен: «GEEN officieel uittreksel / NOT an official KVK extract»,
  указана РЕАЛЬНАЯ дата получения (сегодня).
Если нужен подлинник — только вариант «заказать платную выписку» (человек оплачивает).

1. ЧТО ПРОСИЛ ПОЛЬЗОВАТЕЛЬ (хронология)
------------------------------------------------------------------------------
- Выписка KVK платная; все нужные данные видны на СТРАНИЦЕ РЕЗУЛЬТАТОВ поиска.
- Дал Google-док (копия официального «Uittreksel Handelsregister KvK») и codegen:
    kvk.nl/en/search → «Accept all» → поле «Search in kvk.nl» → fill(имя) → «Search».
- Просил заполнить шаблон, «даты менять на близкие», дата документа = текущая.
- Разные фирмы могут иметь разные типы данных — гонять на нескольких.
- В коде куки принимались («Accept all»), у драйвера сперва не срабатывали.
- Сохранять в WORD (.docx), НЕ PDF.
- Подписать таблицу КАК В СТРУКТУРЕ выписки, тот же порядок, данные напротив строк.
- «Enig aandeelhouder» — спросил, убрали.
- «Deponering jaarstuk» — почему пусто.
- ОДИН файл на весь запрос, каждая фирма — с новой страницы.

------------------------------------------------------------------------------
2. ЧТО РЕАЛЬНО БЕРЁМ С БЕСПЛАТНОЙ СТРАНИЦЫ (и чего НЕТ)
------------------------------------------------------------------------------
ЕСТЬ (заполняем):
    KvK-nummer            ← «KVK number:»
    Rechtsvorm            ← форма в блоке (Besloten Vennootschap и т.д.)
    Statutaire naam       ← «Name given in the articles:»
    Handelsnaam/Handelsnamen ← «Trade names:»
    Vestigingsnummer      ← «Branch number:»
    Bezoekadres           ← строка с индексом (напр. 2408AN)
    Activiteiten          ← абзац «De uitoefening…»

НЕТ на бесплатной странице (оставляем «—», НЕ выдумываем):
    RSIN, Statutaire zetel, Datum akte van oprichting,
    Datum akte laatste statutenwijziging, Rechtsvormwijziging,
    Geplaatst/Gestort kapitaal, Deponering jaarstuk,
    Startdatum onderneming, Werkzame personen,
    Enig aandeelhouder (акционер).

------------------------------------------------------------------------------
3. ПРО BV (Besloten Vennootschap) и «Enig aandeelhouder»
------------------------------------------------------------------------------
- BV — голландское ООО. Самая частая форма, проходит проверку (не 🔴).
- Секция «Enig aandeelhouder» в официальной выписке есть ТОЛЬКО у BV с ОДНИМ
  акционером (тогда его имя/адрес публичны).
    * несколько акционеров → состав НЕ публичен, секции нет;
    * Eenmanszaak / Maatschap / VOF / Stichting → секции нет.
- С бесплатного поиска акционера НЕ видно → секцию убрали (не выдумываем).
- «Deponering jaarstuk» (сдача годового отчёта) — только в платной выписке → прочерк.

7. ПРОЦЕСС РАБОТЫ ПРИЛОЖЕНИЯ (цепочка кода)
------------------------------------------------------------------------------
app.py (окно, вкладка «Скачать выписки», поток)
  → part2\engine.py  run(geo="NL", excel, out_dir="выписки", human, log, sheet)
       • читает лист Excel → список Company
       • создаёт папку прогона выписки\NL\<дата>\
       • открывает браузер (common\browser.py, профиль "NL")
       • ЦИКЛ по фирмам, на КАЖДУЮ — СВЕЖИЙ драйвер Netherlands:
            d.search(c)          → кандидаты (kvk.nl)
            matching (движок)    → выбрать нужную (part2\core\matching.py)
            d.open(выбор)
            d.check(c)           → форма/статус (part2\core\формы.py)
            d.данные_реестра()   → имя/адрес → колонка K
            d.номер()            → KVK → колонка I
            d.fetch(...)         → ДОПИСАТЬ страницу в Нидерланды_выписки.docx
       • пишет Excel (common\human.py: сохранить_excel — не крашит, если открыт)
       • в конце: урезанная копия Excel + не_вышло.xlsx (part2\core\report.py)
  → part2\geos\registry.py  DRIVERS["NL"] = Netherlands
  → part2\geos\netherlands.py  ← ВСЯ логика NL
