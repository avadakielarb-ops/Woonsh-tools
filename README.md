# Woonsh Tools

Windows-приложение. Python устанавливать не требуется.

**[Скачать WoonshTools.exe](https://github.com/avadakielarb-ops/Woonsh-tools/releases/latest/download/WoonshTools.exe)** · [Инструкция](ИНСТРУКЦИЯ.md)

Скачайте EXE в отдельную папку с правом записи и запустите. Source code ZIP для запуска не нужен.
При первом запуске создаётся папка `data/application`: настройки, сессии и рабочие данные остаются только на вашем компьютере. Не удаляйте её при обновлениях и не передавайте другим.

Обновления: **Настройки → Проверить обновления → Обновить и перезапустить**. Проверяется SHA-256. Если новая версия не подтверждает запуск, механизм обновления пытается автоматически восстановить предыдущую.

Релиз не содержит личных ключей и входов владельца. Google и Telegram подключаются пользователем; доступны QR и вход по коду Telegram.

В этом репозитории размещаются готовые релизы и инструкция.
