## 1. ЦСВ ВАЙТ — ppc_gemini.pyw (8129 строк)
**Статус:** ✅ ПРОВЕРЕНО

### ПОТОКОВЫЕ / API ОПТИМИЗАЦИИ (то, что было пропущено):

**A. Двухрежимная генерация: API + Браузер (CDP)**

1. **API-режим** (`generate_draft`, строки 1409–1471): `urllib.request` к Gemini API с `responseMimeType: "application/json"` + `responseSchema`. Авторемонт (до 3 раз): если ответ не JSON — дописывает turn (model reply + fix request).

2. **Браузер-режим** (`browser_generate`, строки 2017–2254): **ЖИВАЯ АВТОМАТИЗАЦИЯ Gemini через Chrome DevTools Protocol**. Самописный WebSocket клиент (0 зависимостей). 6 JS-скриптов вшиты в Python. Поллинг DOM каждые 1.5с, авто-перезагрузка при зависании (SILENCE=90с, FROZEN=150с, 3 попытки). `keep_awake()` + Chrome anti-throttle flags.

**B. Авто-ротация моделей** (строки 1296–1407): `MODEL_CHAIN` из 4 моделей. При 429 — мгновенно следующая модель, без паузы. `RateLimited` различает минутный/дневной лимит. Thread-safe.

**C. Retry с Retry-After** (строки 1207–1284): 5 попыток, слушает `Retry-After` header и `retryDelay` из тела ответа Google.

**D. Batch queue** (BatchWindow, строки 6638–8000+): batch-процессор с персистентным буфером (`batch.json`). Авторемонт в цикле (`while errors and rounds < AUTO_ROUNDS_MAX`), stall detection, `follow_up=True` (только замечания), `chat_url` persistence.

### Другие преимущества: валидация контента (бан gambling/casino/pharma/crypto), DKI-aware length check, отдельные промпты для агрегаторов, CSV для Google Ads Editor, тема Aurora, 0 внешних зависимостей.

### Проблемы: монолит 8129 строк, Chrome-режим хрупкий (DOM-зависимость).

## 3. X-FILE ADS — ads_generator/ + ads_bridge + ads_native + ads_review + ads_selectors + ads_validation
**Статус:** ✅ ПРОВЕРЕНО

### ads_generator/app.py (1056 строк) — Standalone HTTP-генератор

**Архитектура:** Локальный HTTP-сервер (localhost:8765) с web-UI, ThreadingHTTPServer.

**Плюсы:**
- **ThreadPoolExecutor(max_workers=4)** для параллельной загрузки страниц сайта (fetch_site)
- **ThreadPoolExecutor(min(4, N))** для параллельной генерации кампаний (build_site → work)
- **Динамическая модель discovery:** `available_models()` запрашивает Google API, кэш 1 час, приоритет flash-lite
- **THINK_LADDER** — управление thinking budget: tries thinkingBudget:0 → thinkingLevel:"minimal" → None, запоминает per-model
- **model_order()** — env GEMINI_MODEL → last-good → dynamic list → FALLBACK_MODELS
- **llm_json()** — 3 попытки с разными температурами (0.7→0.4→0.2)
- **parse_json_loose()** — 4-уровневая цепочка ремонта JSON: raw → trailing commas → unquoted keys → curly quotes
- **policy_issue()** — валидация Google Ads policy: superlatives, "click here", пунктуация, символы, телефоны, ALL-CAPS
- **sentence_case()** — конвертация Title Case → sentence case (skip German)
- **Встроенные негативные ключевые слова на 8 языках** (en, ru, uk, de, es, fr, pl, lv)
- **fetch_site()** — HTMLParser-based извлечение + sitemap fallback + ThreadPoolExecutor(4) для доп. страниц
- **plan_site() / write_campaign()** — structured JSON промпты с правилами Google Ads policy
- **Авторемонт кампании:** до 3 попыток fix через ads_validation.check() → LLM correction
- **History** с atomic writes (tmp→replace), HISTORY_KEEP лимит
- **Regeneration** — перегенерация одной кампании без повтора всего
- **ZIP-export** — по одному CSV на сайт
- **Redact API keys** в ошибках (AIza pattern)
- **180с deadline** на LLM-вызов, 2 retry per model on 429/503

**Минусы:**
- Внешний HTTP-сервер вместо встроенного GUI — лишний компонент
- Зависимость от Playwright/HTMLParser для парсинга сайтов
- JOBS dict в памяти — при перезапуске теряются незавершённые
