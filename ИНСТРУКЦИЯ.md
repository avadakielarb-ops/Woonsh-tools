# Woonsh Tools: подключение и работа

Переносимая EXE-сборка 0.1.41. Официальные обновления: https://github.com/avadakielarb-ops/Woonsh-tools/releases/latest .

## Установка

Скачайте WoonshTools.exe из официального релиза, положите в отдельную папку, в которую у вас есть право записи, и запустите. Архив исходников Source code для запуска не нужен. Python устанавливать не нужно. Для работы с сайтами нужен Google Chrome; rclone устанавливается кнопкой «Скачать rclone» в настройках. Нужен интернет для подключений и работы сервисов.

По умолчанию программа создаёт рядом с EXE папку `data/application`. Здесь остаются настройки, защищённые сессии, задания и служебные данные. Папки Фирм и CSV можно назначить в настройках. Не удаляйте папку data при обновлении и не отправляйте её другим людям. На компьютере владельца распаковывайте внутри W:\Вайб кодинг\Wunsh.

Для подключения уже существующей папки данных без копирования создайте рядом с EXE файл `data-location.json` с содержимым `{"data_dir":"D:/WoonshData"}`, заменив пример своим путём. Закройте приложение перед изменением пути. Перенос на другой компьютер может потребовать повторного входа: DPAPI привязан к пользователю Windows. Чистая сборка сама не ищет чужие старые настройки.

## Настройка

1. Выберите рабочие папки для Фирм и CSV в настройках. Для текущей установки владельца используются папки на W:. Не храните рабочие данные в каталоге временной распаковки программы.
2. Войдите в Google через профиль Woonsh. В настройках укажите рабочую Google-таблицу с листом **Аккаунты** и нажмите **Проверить лист «Аккаунты»**. Профили, Шипау и Таблицы используют эту таблицу.
3. Для облачной базы Фирм отдельно задайте опубликованный Apps Script URL, заканчивающийся на `/exec`, и ключ доступа этого скрипта. Ссылка на редактор или Google Sheets не заменяет URL скрипта. Нажмите проверку базы. Вход в Google и ключ Apps Script — разные подключения; таблицу не требуется делать общедоступной.
4. В Telegram задайте API ID, API hash и свой номер, сохраните настройки. Основной способ — **Войти в Telegram по QR**: на телефоне откройте Telegram → Настройки → Устройства → Подключить устройство, отсканируйте QR. Альтернативный вход по номеру и коду остаётся рядом. Если включена двухэтапная защита, потребуется её пароль. Просроченный QR запросите снова. Токен BotFather сюда не подходит.
5. Подключите Google Drive. В разделе Drive укажите папку конкретного клиента и проверьте доступ. Авторизация аккаунта и ссылка на папку — разные настройки. Обновление приложения не должно требовать повторного подключения действующих аккаунтов.

Не публикуйте ключи, сессии или рабочую папку. Настройки со значением «сохранено» ещё не означают, что сервис ответил успешно.

## Фирмы, Таблицы, Профили и Шипау

- **Фирмы:** выберите гео/мультигео и режим. Проверка ботом входит в соответствующий цикл автоматически; ручные шаги нужны для капчи или неоднозначных данных. Окно ожидающей капчи не закрывайте. После её решения нажмите «Продолжить» в приложении.
- **Таблицы:** B — профиль, G — платёжные данные, H — ссылка на выписку, I — гео. Выберите строки чекбоксами, кликом или Shift и нужный фильтр. Если G заполнена, а H пустая, задача ищет именно эту фирму; старая выписка для первого скачивания не требуется. При тёзках используется адрес. Если выписка недоступна, результат не должен выдаваться за успешно выполненный.
- Документы собираются перед пакетной загрузкой в выбранную папку Drive. Завершение проверяйте по файлам и ссылкам в целевых строках, а не только по надписи «скачано».
- **Профили:** работа с одним аккаунтом. **Шипау:** диапазон строк того же листа Аккаунты преобразуется в табличное представление; клик копирует значение. Редактирование в Шипау не предусмотрено.
- Для выданной фирмы статусы основной базы и служебного Реестра должны стать «отработано». Если облачная запись не подтверждена, повторное завершение должно оставаться доступным.

## Обновления

EXE проверяет опубликованные GitHub Releases репозитория avadakielarb-ops/Woonsh-tools. Пока владелец не опубликовал релиз, отсутствие обновления нормально. Не скачивайте рабочую версию из случайной ветки вместо релиза.

Завершите активные задания, откройте проверку обновлений и подтвердите установку. Перед заменой сверяются размер и SHA-256. При ошибке скачивания программа остаётся прежней. После замены новая версия должна подтвердить запуск; при отказе запуска возвращается предыдущий EXE. Рабочая папка данных не заменяется. Результат и ошибка установки находятся в `data/application/updates` (либо updates выбранной папки данных).

## Известные ограничения

Доступность реестров меняется. Венгрия требует человека для капчи; Швеция отложена. Латвийский сервис сообщал о временной недоступности выписок. Второе новое немецкое скачивание не завершено. Повторяющиеся сетевые ошибки не следует устранять быстрыми повторными запросами.
