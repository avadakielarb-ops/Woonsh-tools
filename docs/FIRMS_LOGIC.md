# Поиск Фирм — Логика работы

## Два режима поиска

### С сайтом (DnB)
```
Слово → DnB (Playwright) → список фирм с сайтами
  → фильтрация (страна, дубли, реестр)
  → запись в Google Таблицу (лист "С сайтом")
  → если попалась фирма БЕЗ сайта → пишем в лист "Без сайта"
```

### Без сайта (Реестр)
```
Слово → гео-драйвер реестра → список фирм без сайтов
  → фильтрация (дубли, реестр)
  → запись в Google Таблицу (лист "Без сайта")
  → если попалась фирма С сайтом → пишем в лист "С сайтом"
```

**Оба варианта**: DnB через Playwright с паузами (не HTTP-запросы).
Реестр — через гео-драйвер страны (Playwright или requests, зависит от страны).

## Полный поток (стандартный режим)

### Этап 1: Генерация слов
```
Gemini API → список поисковых слов для страны/отрасли
  → MODEL_CHAIN: gemini-3.8-flash → 3.6 → 3.5-lite → 3.1-lite
  → ротация на 429, определение дневного лимита
  → кнопка "Пересмотреть слова" — перегенерация
```

### Этап 2: Поиск фирм
```
Для каждого слова:
  DnB (Playwright):
    → открыть поиск → ввести слово + страна
    → паузы между действиями (anti-bot)
    → собрать результаты: название, адрес, сайт, телефон
    → фильтрация:
      - дубли (по названию + адресу)
      - уже в реестре (LocalFileRegistry)
      - страна совпадает с запрошенной
    → запись в Google Таблицу
    → обновление статуса: "Слово 3/10, найдено: 47"
```

### Этап 3: Скачивание выписок
```
Для каждой найденной фирмы:
  → гео-драйвер страны:
    search(name) → open(result) → check(page) → fetch(extract)
  → скачивание PDF через РЕАЛЬНЫЙ профиль браузера
    (Cloudflare защита — нужен профиль с cookies)
  → сохранение в папку выписок
  → retry + backoff: 3 попытки (2с / 4с / 8с)
```

### Этап 4: Проверка у бота (АВТОМАТИЧЕСКАЯ)
```
После скачивания выписки:
  → отправка данных Telegram-боту (python-telegram-bot API)
  → бот проверяет: компания не меняла имя? не в чёрном списке?
  → получение ответа автоматически
  → обновление статуса в Google Таблице:
    ✓ Годная | ✗ Отклонена | ⚠ Требует проверки
  → НЕТ ручного копирования — всё через API
```

### Этап 5: Взять в работу (Tab 2)
```
Пользователь:
  → выбирает гео (страна)
  → указывает количество (без ограничений)
  → нажимает "Взять в работу"
Система:
  → берёт N годных фирм из указанного гео
  → создаёт папку: "{дата}_{гео}_{количество}"
  → копирует выписки (PDF) в папку
  → создаёт Excel с платёжной информацией
  → обновляет статусы в Google Таблице: "Выдана"
```

## HumanGate (ручное управление)

Правая панель / секция в Tab 1.

**Чекбокс «Автономно»** — работает во ВСЕХ режимах:
- ВКЛ: бот работает без остановок, решения принимает сам
- ВЫКЛ: останавливается на каждом решении, ждёт пользователя

**Переключается НА ХОДУ** — через `threading.Event`:
```python
class HumanGate:
    autonomous = threading.Event()

    def ask(self, question, options):
        if self.autonomous.is_set():
            return self._auto_decide(question, options)
        # показать вопрос в UI, ждать ответа
        self.answer_event.wait()
        return self.answer
```

**Типичные вопросы HumanGate:**
- "Фирма X похожа на дубль Y. Пропустить?" → авто: пропустить
- "Реестр не отвечает. Повторить?" → авто: повторить 3 раза
- "Слово дало 0 результатов. Следующее?" → авто: следующее

## LocalFileRegistry (реестр фирм)

Два уровня:
1. **БРОНЬ** — по имени фирмы, TTL 24 часа, привязана к фармеру
2. **ПОДТВЕРЖДЕНИЕ** — по официальному номеру, навсегда

```
Поиск → нашли фирму → бронь(имя, фармер) → 24ч на скачивание выписки
Выписка скачана → подтверждение(номер_из_выписки) → навсегда в реестре
```

- 30 бэкапов файла реестра
- Проверка дублей ПЕРЕД записью: и по имени (бронь), и по номеру (подтверждение)
- Retry + backoff при ошибках файловой системы

## Гео-драйверы (19 стран)

ABC (базовый класс):
```python
class GeoDriver(ABC):
    @abstractmethod
    def search(self, name: str) -> list[dict]:
        """Поиск фирмы по имени в реестре страны"""

    @abstractmethod
    def open(self, result: dict) -> str:
        """Открыть страницу фирмы, вернуть URL"""

    @abstractmethod
    def check(self, page) -> bool:
        """Проверить: фирма активна? данные полные?"""

    @abstractmethod
    def fetch(self, page) -> Path:
        """Скачать выписку (PDF), вернуть путь к файлу"""
```

**Страны**: CZ, CH, PL, AT, UK, NO, HU, DK, US (только определённые штаты, поиск на DnB — скачивание нет), FR, SI, EE, BE, HR, LV, AU, FI, BG, NL

**⚠️ NL (Нидерланды) — НЕ ТРОГАТЬ. Код работает, не менять.**

**USA особенность**: поиск на DnB работает, скачивание выписок — нет.
Поиск по определённым штатам (FL и др.).
