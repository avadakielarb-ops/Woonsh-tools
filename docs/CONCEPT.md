# Woonsh Tools — Полная концепция проекта

## Что это

Десктопное приложение (tkinter, Windows) объединяющее 5 инструментов в одном окне.
Два режима запуска через `launcher.pyw`: **Farmer** (мультифармер) и **Woonsh Tools** (основное).

**Три источника кода:**
1. **Фирмы/** — код владельца (183 файла, ~19500 строк, 83 теста). **ЭТО БАЗА. Логику не менять до неузнаваемости.**
2. **ЦСВ Вайт/** — код владельца (ppc_gemini.pyw, 8129 строк монолит). **ЭТО БАЗА для CSV генератора.**
3. **X-File/** — код коллеги (x-file.pyw + модули). Дополнения: Drive, профили, документы, Playwright DnB. **Равен коллеге = брать как есть.**

## Что обсуждалось и к чему пришли

### ПОИСК ФИРМ — детально обсуждён, логика согласована

**Два режима поиска:**
- **С сайтом** — через DnB (Playwright с паузами, НЕ HTTP-запросы)
- **Без сайта** — через гео-драйвер реестра страны, или DnB → потом реестр

**ВСЕ фирмы записываются:** если искали "с сайтом" и попалась без — пишем в лист "Без сайта", и наоборот.

**Переключатель режима работы (в Tab 1):**
- Стандартный (поиск + выписки) — ищем фирмы, потом качаем выписки
- Только поиск фирм — только поиск, без скачивания

**Полный поток (стандартный режим):**
1. Генерация слов (Gemini API, MODEL_CHAIN: 4 модели с ротацией на 429)
2. Поиск фирм (DnB через Playwright / гео-драйвер реестра)
3. Фильтрация (дубли, реестр LocalFileRegistry, страна)
4. Запись в Google Таблицу (лист "С сайтом" / "Без сайта")
5. Скачивание выписок (через РЕАЛЬНЫЙ профиль браузера — Cloudflare защита)
6. Проверка у бота — **АВТОМАТИЧЕСКАЯ** через Telegram API, НЕ ручная
7. Обновление статусов в таблице: Годная / Отклонена / Требует проверки

**Tab 2 — Гео и выдача:**
- Таблица по странам (всего, с выпиской, годные, выдано)
- Кнопка "Докачать выписки" — для режима "Только поиск"
- "Взять в работу": выбрать гео + количество (БЕЗ ОГРАНИЧЕНИЙ) →
  создаётся папка с выписками PDF + Excel с платёжной инфой

**HumanGate (ручное управление):**
- Чекбокс "Автономно" — работает во ВСЕХ режимах, не только "С сайтом"
- Переключается НА ХОДУ через threading.Event
- Вкл: бот работает без остановок
- Выкл: останавливается на каждом решении

**LocalFileRegistry (реестр фирм):**
- БРОНЬ — по имени, TTL 24ч, привязана к фармеру
- ПОДТВЕРЖДЕНИЕ — по официальному номеру, навсегда
- 30 бэкапов, retry + backoff (3 попытки, 2с/4с/8с)

**19 гео-драйверов:** CZ, CH, PL, AT, UK, NO, HU, DK, US (определённые штаты, скачивание нет), FR, SI, EE, BE, HR, LV, AU, FI, BG, NL
- **⚠️ NL (Нидерланды) — НЕ ТРОГАТЬ. Код работает, не менять.**
- ABC: search/open/check/fetch
- США: поиск на DnB работает, скачивание выписок — нет

**Интерфейс Tab 1:**
```
[Переключатель: Стандартный / Только поиск]

Режим:     ○ С сайтом  ○ Без сайта
Источник:  [только для "Без сайта"] ○ DnB → Реестр  ○ Сразу реестр
Страна:    [▼ выпадающий]  ☐ Мультигео → [окно выбора стран]
Слово:     [____________] (пусто = все)
Кол-во:    [____________] (без ограничений)
☐ Автономно

[▶ Старт] [⏸ Стоп] [🔄 Пересмотреть слова]

Статус бар: что делает бот сейчас
HumanGate: вопросы (если не автономно)
```

**Что удалено:** Функция "поиск сайтов" (Part 3 из оригинала) — ПОЛНОСТЬЮ УБРАНА.

### ЦСВ ВАЙТ (= Google Ads → Компании) — детально обсуждён

**Суть:** генерация CSV-кампаний для Google Ads через Gemini.

**Поток:**
1. Ввод URL + описание сайта
2. Генерация черновика (Gemini) → JSON
3. Валидация (600+ строк: гео, язык, banned topics, символы, длины, обрубки, числа)
4. Человек проверяет → правка или регенерация
5. Сборка CSV → файл для загрузки в Google Ads

**Ключевые механизмы (из кода владельца — СОХРАНИТЬ):**
- **MODEL_CHAIN** — 4 модели Gemini, ротация на 429, определение дневного лимита
- **Валидация 600+ строк** — полная система: гео, язык, English ratio, banned topics (15 категорий), числа, посадочная, обрубки
- **Repair loop** — multi-turn с памятью ошибок, детект рецидивов ("ТИ ВЖЕ ВИПРАВЛЯВ ЦЕ"), детект обрубков
- **Banned topics** — TOPICS_SUSPEND (моментальная блокировка) vs обычные, многозначные слова
- **CDP/WebSocket** — raw socket, Chrome DevTools Protocol, keep_awake() (свёрнутая вкладка = 10x замедление)
- **BatchWindow** — canvas-таблица как мини-Excel, Ctrl+V из Google Таблиц, тяни ширину колонки
- **Промпт** — внешний файл prompt_gemini.txt, версионированный (v99)
- **Гео-система** — country_scores(), TLD_COUNTRY, защита от ложного гео
- **CSV-сборка** — build_rows, write_csv, free_path() (не перезаписывает!)
- **Варианты** — 4 STRUCTURES × 8 NAME_ANGLES × 5 PHRASINGS × 5 ACCENTS = 800 комбинаций

**Что добавить от коллеги (X-File):**
- **BUILTIN_NEG** — негативные ключевые слова по 8 языкам (en, ru, uk, de, es, fr, pl, lv)
- **THINK_LADDER** — автоподбор бюджета мышления (простой сайт → дешевле)
- **ThreadPoolExecutor(4)** — параллельная генерация для batch

**Что НЕ менять:**
- Валидация — в разы глубже чем у коллеги, не упрощать
- Repair loop с памятью — у коллеги нет, наш лучше
- Banned topics — 15 категорий vs ничего у коллеги
- Промпт — версионированный, внешний файл
- BatchWindow — полноценная таблица vs просто список URL

**Разбиение монолита (8129 строк → модули):**
```
ppc_gemini.pyw → woonsh_tools/ads/
  validation.py   (~600 строк) — вся валидация
  banned.py       (~300 строк) — banned topics regex + проверки
  generator.py    (~400 строк) — генерация + repair loop
  geo.py          (~200 строк) — определение гео
  csv_builder.py  (~200 строк) — build_rows + write_csv
  batch.py        (~600 строк) — BatchWindow
  negatives.py    — BUILTIN_NEG по языкам (от коллеги)
  panel.py        (~500 строк) — App + UI
  prompt_gemini.txt — промпт (версионированный)
```

## Критические ограничения

1. **NL (Нидерланды)** — НЕ ТРОГАТЬ код гео-драйвера
2. **Папка "не трогать"** — не читать, не менять
3. **Логика владельца = БАЗА** — не менять до неузнаваемости
4. **Владелец решает что менять** — АИ предлагает, владелец решает
5. **Функция "поиск сайтов" удалена** — не возвращать
6. **Количество на страну** — без ограничений
7. **Бот-проверка** — АВТОМАТИЧЕСКАЯ через API, не ручная
8. **DnB** — через Playwright с паузами, не HTTP-запросы
9. **Выписки** — через реальный профиль браузера (Cloudflare)
10. **"Автономно"** — чекбокс во ВСЕХ режимах

## План реализации

### Этап 1: Поиск фирм (companies/)

5. Перенести `queue.py` — очередь заданий (слово × страна × количество)
6. Перенести `search_dnb.py` — DnB через Playwright
7. Перенести `words_gemini.py` — генерация слов через Gemini
8. Перенести `filters.py` — фильтрация (страна, дубли)
9. Перенести `delivery.py` — выдача (папка + Excel)
10. Перенести `bot_check.py` — автоматическая проверка у Telegram-бота

12. Переделать `stats.py` → полноценная "Гео и выдача" с кнопкой "Докачать"

### Этап 2: ЦСВ Вайт (ads/)
1. Разбить ppc_gemini.pyw на модули (validation, banned, geo, csv_builder, batch)
2. Перенести валидацию (600+ строк) в `validation.py`
3. Перенести banned topics в `banned.py`
