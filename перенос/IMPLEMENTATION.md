# План реализации

> Каждый этап заканчивается: офлайн-тесты зелёные → коммит → владелец проверяет у себя на Windows.
> Владелец проверяет вживую — **не делать несколько этапов вслепую подряд.**
> Не пройден критерий «готово» — не переходить дальше.

## Этап 0. Подготовка (0.5 дня)

1. Прочитать: `перенос/README.md` → `CONCEPT.md` → `FIRMS_LOGIC.md` → `CSV_LOGIC.md` → `MODULE_MAP.md` → `Фирмы/доки/CLAUDE.md`.
2. Посмотреть `перенос/img/firms_window_original.png`, `перенос/UI_MOCKUP.html` (открыть в браузере).
3. `ЗАПУСК.bat`: создавать `.venv` на **Python 3.12** (`py -3.12 -m venv .venv`), ставить зависимости, `playwright install chrome` не нужен (используется установленный Chrome), Playwright ≥ 1.62. Сейчас у владельца запускается 3.14 — колёс нет.
4. Объединить `requirements.txt` (сейчас там зависимости раннего каркаса `woonsh/` — customtkinter, gspread и т.д., которые не используются): playwright, playwright-stealth, openpyxl, python-docx, telethon<2, pymupdf (для документов коллеги — сверить с X-File), без лишнего.

**Готово:** двойной клик `ЗАПУСК.bat` на чистой Windows поднимает launcher, оба режима открываются.

## Правила работы для ИИ

- Писать владельцу по-русски, коротко, без жаргона. Владелец раздражается, когда его переспрашивают о том, что видно в файлах — **сначала смотреть код и доки**.
- Перед правкой кода владельца — показать, что меняется и зачем, дождаться «да».
- Коммит после каждого шага, сообщение «что и почему». Ветка — та, что указал владелец.
- Не трогать `не трогать/` и `netherlands.py`.
- Не «улучшать» то, о чём не просили. Список согласованного — `CONCEPT.md` §5–6.
