# АУДИТ: ЦСВ Вайт (ppc_gemini.pyw)

## АРХИТЕКТУРА

**Один файл — 8129 строк.** Всё в одном: UI, генерация, валидация, CDP-браузер, CSV-сборка, batch-очередь.

**Два режима работы:**
- **Браузер** — открывает Chrome через CDP (WebSocket), шлёт промпт в веб-Gemini, забирает ответ
- **API** — прямые HTTP-запросы к Gemini API с ключом

**Основной поток:**
1. Ввод URL + описание сайта
2. Генерация черновика (Gemini) → структурированный JSON
3. Валидация (ошибки блокируют CSV, предупреждения — нет)
4. Человек проверяет → ручная правка или регенерация с комментарием
5. Сборка CSV → файл для загрузки в Google Ads

**Batch-режим (BatchWindow):**
- Таблица как в Excel: профиль × сайт × описание
- Ctrl+V из Google Таблиц, ширину колонки тянешь за край
- Очередь: генерируем все, потом разбираем: чистые сохраняем, грязные перегенерируем
- Буфер (batch.json): запрос + сырой ответ → можно дослать в тот же чат

## КЛЮЧЕВЫЕ МЕХАНИЗМЫ

### 1. MODEL_CHAIN / AUTO_MODEL (строки 1296-1407)
4 модели Gemini по цепочке на 429:
```
gemini-3.8-flash → gemini-3.6-flash → gemini-3.5-flash-lite → gemini-3.1-flash-lite
```
- `auto_chain()` — валидирует цепочку против доступных моделей ключа
- `_call_model()` — ротация на RateLimited, определение дневного лимита
- Определение next reset: парсит Retry-After, считает до следующей полуночи PT
- Per-model кулдаун с ежедневным сбросом

### 2. Валидация (строки 3766+, ~600 строк)
Самая толстая часть файла. Проверяет ВСЁ:
- **Гео**: Location нормализация, совпадение с описом сайта, GEO_SUSPENDED
- **Язык**: должен быть языком СТРАНЫ (не языком описания сайта)
- **English ratio**: если кампания якобы чешская, а 8%+ слов английские — ошибка
- **Посадочная страница**: мёртвая? редирект на другой домен? объекты есть на странице?
- **Числа**: «Přes 200 her» — откуда 200? Нет в описании → ошибка
- **Banned topics** (~15 категорий): казино, оружие, наркотики, adult, фин. обещания
  - `TOPICS_SUSPEND` — моментальная блокировка аккаунта
  - Многозначные слова: «παιχνίδια» = игры И иг рушки — требует уточнения
- **Ключевые слова**: ровно 15, баланс коротких/длинных/предметных/английских
- **Заголовки**: ровно 15 × до 30 символов, 1-4 с макросом, ≤2 с гео
- **Описания**: ровно 4 × 60-90 символов
- **Символы**: ZERO TOLERANCE — только буквы, цифры, пробілы (кроме описов)
- **Callouts**: ровно 8, до 25 символов
- **Snippets**: тип ТОЛЬКО на английском (Amenities, Brands...), значения на языке кампании
- **Обрубки**: «Sezonni Menu Na Letni Ter» — переписать, а не обрезать
- **Социальное казино**: отдельный блок (страны, бесплатность, группы)

### 3. CDP/WebSocket (строки 1475-1620)
Полностью своя реализация:
- **WebSocket** — raw socket, ручной handshake, фреймы, маскирование
- **Tab** — `evaluate(js)` и `command(method, params)` через CDP
- **keep_awake()** — Emulation.setFocusEmulationEnabled + Page.setWebLifecycleState
  - Без этого свёрнутая вкладка тормозит: Gemini печатает в 10 раз дольше
- **Chrome launch** — отключение фоновых таймеров, CalculateNativeWinOcclusion
  - `--disable-background-timer-throttling`
  - `--disable-backgrounding-occluded-windows`
  - `--disable-renderer-backgrounding`
  - Один `--disable-features` (два перебьют друг друга!)
  - OptimizationGuideOnDeviceModel отключён (Gemini Nano = 4GB мусора в профиле)

### 4. Промпт-система (prompt_gemini.txt, 160 строк)
Версионированный промпт (ВЕРСІЯ: 99). Блоки:
- КРОК 0: определи ГЕО, ЯЗЫК, ЦІЛЬОВІ ОБ'ЄКТИ
- БЛОК 1: ЗАПРЕЩЁННЫЕ ТЕМЫ (казино, лекарства, оружие, adult...)
- БЛОК 2: КЛЮЧОВІ СЛОВА — ровно 15, баланс по типам
- БЛОК 3: ANTI-FLUFF — только то, что есть на сайте
- БЛОК 4: СИМВОЛИ — zero tolerance
- БЛОК 5: ОГОЛОШЕННЯ — 15 заголовків, 4 описи
- БЛОК 6: РОЗШИРЕННЯ — callouts, snippets, sitelinks
- ФОРМАТ: только JSON, без пояснень

### 5. Repair loop (строки 1409-1472, 4428-4482)
Multi-turn дослание в тот же чат:
- `generate_draft()` — 3 попытки на ошибки формата (FIX_FORMAT_NOTE)
- `build_repair_notes()` — валидация → список исправлений → дослание
- **Рецидивы**: «ТИ ВЖЕ ВИПРАВЛЯВ ЦЕ» — если ошибка повторяется после исправления
- **Обрубки**: «ТИ ОБРІЗАВ ЗАМІСТЬ ТОГО, ЩОБ ПЕРЕПИСАТИ» — детектит обрезанные слова
- `repair_snapshot()` — снимок текущего состояния для контекста
- `COUNTING_RULE` — инструкция по подсчёту символов (díакритика = 1 символ)

### 6. Geo-система (строки 3500-3730)
- `country_scores()` — подсчёт упоминаний стран/городов/адресов по тексту
- `TLD_COUNTRY` — маппинг доменов на страны
- `geo_from_notes()` — гео из уточнений пользователя
- `normalize_location()` — нормализация к названию Google Ads
- **Защита**: ресторан на .fr с итальянским меню → гео = France (по домену), а не Italy (по кухне)

### 7. CSV-сборка (строки 4527-4670)
- `build_rows()` — кампания + группы + ключи + объявления + расширения → rows
- `write_csv()` — DictWriter с UTF-8 BOM, безопасные имена файлов
- `free_path()` — уникальные имена (не перезаписывает старый файл!)
- Sitelinks выключены по умолчанию (URL с якорями #1-#6 = обход систем Google)
- Галочки (sitelinks, negatives, callouts, snippets) сильнее модели

## ФИШКИ (лучшее)

1. **Валидация на 600+ строк** — покрывает ВСЁ: гео, язык, символы, длины, banned topics, обрубки, числа, посадочную. Это не «проверил длину» — это целая система фильтрации для Google Ads.

2. **Repair loop с памятью** — рецидивы и обрубки детектятся и называются вслух. Модель видит свои прошлые ошибки. Не «перегенерируй», а «ты уже это ломал, не повторяй».

3. **Banned topics с контекстом** — не просто regex, а TOPICS_SUSPEND (моментальная блокировка) vs обычные. Двузначные слова (παιχνίδια) учтены.

4. **CDP без библиотек** — WebSocket + Chrome DevTools Protocol на raw socket. Никаких зависимостей, работает всюду. keep_awake() — реальная проблема решена (свёрнутая вкладка = 10x замедление).

5. **BatchWindow = мини-Excel** — Canvas-таблица с inline редактированием, Ctrl+V из Google Таблиц, тяни ширину колонки, Shift/Ctrl+клик. Для массовой работы это ключевое.

6. **free_path()** — не перезаписывает файл. Два прогона на один аккаунт = два файла. Мелочь, но без неё теряешь работу.

7. **ANTI-FLUFF в промпте** — «только то, что на сайте». «Přes 200» если нет числа в описании = ошибка. Защита от вранья модели.

8. **Гео не по одному слову** — `country_scores()` считает ВСЕ упоминания. Один раз сказал «Italy» в описании ресторана во Франции — это не гео.

9. **Модель AUTO с цепочкой** — 4 модели, ротация на 429, определение дневного лимита, автоматический next reset. Вставил ключ — работает.

10. **Варианты (variant system)** — 4 STRUCTURES × 8 NAME_ANGLES × 5 PHRASINGS × 5 ACCENTS = 800 комбинаций. Каждая генерация уникальна.

## СЛАБЫЕ МЕСТА

1. **8129 строк в ОДНОМ файле.** UI, CDP, валидация, CSV, batch, промпт, гео, banned topics — всё вместе. Найти нужное сложно. Изменить одну часть — рискуешь сломать другую.

2. **Нет тестов.** Валидация на 600 строк — и ни одного теста. Поменял regex в banned topics — как убедиться, что не сломал легальные слова?

3. **Промпт на украинском, код на смеси украинского и английского.** Комментарии на украинском, переменные на английском, UI на украинском. Для одного разработчика ОК, для команды — барьер.

4. **CDP-браузер хрупок.** Raw WebSocket — это круто, но: нет reconnect при обрыве, нет retry на evaluate, таймаут 60с жёсткий. Chrome обновился — и всё может сломаться.

5. **BatchWindow не запоминает состояние таблицы при крахе.** Буфер (batch.json) хранит очередь, но заготовка (stage) — нет. Набил 100 строк, крахнулось — набивай заново.

6. **Нет rate limiting на уровне приложения.** MODEL_CHAIN обрабатывает 429, но нет proactive throttling. При массовом запуске 50 сайтов — всё равно упрёмся в лимиты.

7. **Sitelinks по умолчанию выключены** — правильно (из-за якорей), но если у сайта реальные страницы — нет способа включить с реальными URL.

8. **Нет истории генераций.** Сгенерировал, закрыл, открыл — ничего нет. Только CSV остался. Для анализа «что генерили для этого сайта месяц назад» — никак.

### Что у коллеги лучше:
1. **Модульность** — 6 файлов vs 1 монолит. Каждый модуль < 400 строк.
2. **ThreadPoolExecutor(4)** — параллельная генерация кампаний. Для batch в 4 раза быстрее.
3. **BUILTIN_NEG** — негативные ключевые слова по языкам (en, ru, uk, de, es, fr, pl, lv). Не зависит от модели.
4. **THINK_LADDER** — автоподбор бюджета мышления. Простой сайт → меньше токенов → быстрее и дешевле.
5. **Web UI** — доступ из любого браузера, легче стилизовать, обновлять без перезапуска.

### Что у тебя лучше:
1. **Валидация** — в разы глубже. policy_issue() у коллеги — базовая проверка. У тебя — полная система с гео, языком, banned topics, числами, посадочной, обрубками.
2. **Repair loop** — дослание в тот же чат с памятью ошибок. У коллеги — просто перегенерация.
3. **Banned topics** — 15 категорий vs ничего. Это защита аккаунта.
4. **Промпт** — версионированный внешний файл. Можно менять без перекомпиляции.
5. **BatchWindow** — полноценная таблица с Ctrl+V из Excel. У коллеги — просто список URL.
6. **free_path()** — не перезаписывает файлы. Мелочь, но коллега этого не делает.

## ЧТО МОЖНО УЛУЧШИТЬ

### Быстрые победы:
1. **Разбить на модули** — вынести из ppc_gemini.pyw:
   - `validation.py` (~600 строк) — вся валидация
   - `banned_topics.py` (~300 строк) — regex + проверки
   - `cdp.py` (~200 строк) — WebSocket + Tab + Chrome
   - `csv_builder.py` (~200 строк) — build_rows + write_csv
   - `geo.py` (~200 строк) — определение гео
   - `batch.py` (~600 строк) — BatchWindow
   - Главный файл: App + UI + генерация (~1500 строк)

2. **BUILTIN_NEG от коллеги** — добавить встроенные негативные ключевые слова по языкам. Модель не всегда их генерирует.

3. **Сохранение заготовки** — BatchWindow stage (таблица) должна сохраняться в файл, как очередь.

### Средние:
4. **ThreadPoolExecutor для batch** — параллельная генерация (2-4 потока). С rate limiting: не больше N запросов в минуту.

5. **THINK_LADDER от коллеги** — автоподбор бюджета мышления. Простой сайт → дешевле.

6. **Тесты для валидации** — хотя бы 20-30 кейсов: правильная кампания, кампания с banned topics, с неправильным гео, с обрубками. pytest, можно без UI.

### Большие:
7. **История генераций** — JSON-лог: дата, URL, описание, результат, ошибки. Для аналитики и повторов.

8. **Reconnect в CDP** — при обрыве Chrome-соединения пытаться переподключиться, а не падать.
