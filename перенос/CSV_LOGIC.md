## 2. Новое (согласовано владельцем)

### 2.1 Переключатель Search / YouTube

```
┌──────────┐ ┌──────────┐
│◉ Search  │ │○ YouTube │   ← вверху окна «Компании»
└──────────┘ └──────────┘
```
- **Search** — нынешний ЦСВ Вайт без изменений.
- **YouTube** — свой промпт `prompt_youtube.txt` (ещё не написан — открытый вопрос), свои поля
  (URL видео/канала, таргетинг), свой CSV для Video-кампаний.
- Общее: Gemini-движок, MODEL_CHAIN, CDP, banned topics, repair loop, BatchWindow, история.

### 2.2 Batch: «Профіль + Сайт» / «Профіль + Сайт + Опис»

Переключатель над таблицей BatchWindow.
- **Профіль + Сайт** — 2 колонки, колонка «Опис» скрыта, описание берётся с сайта автоматически (`fetch_landing` 1140 + `page_text` 1131).
- **Профіль + Сайт + Опис** — как сейчас, 3 колонки.

### 2.3 От коллеги (X-File)

| Что | Откуда | Куда |
|---|---|---|
| **BUILTIN_NEG** — минус-слова на 8 языках (en ru uk de es fr pl lv) | `X-File/ads_generator/app.py:51-75` | `ads/negatives.py`; в `build_rows` добавлять к минус-словам модели, если стоит галочка «Мінус-слова». Без дублей |
| **THINK_LADDER** | `X-File/ads_generator/app.py:305-320` | Только режим API: бюджет мышления по длине описания |
| **Параллельная очередь** | `X-File/ads_generator/app.py:251, 743` (`ThreadPoolExecutor`) | `BatchWindow._runner` 7855: до 4 кампаний одновременно (число — настройка), с ограничением запросов в минуту. **Только режим API.** В режиме Браузер — по одной (одна вкладка Gemini) |
| **Телефон в тексте** | `policy_issue()` в `X-File/ads_generator/app.py` | Новая проверка в `_validate_ad` → ошибка |
| **Ссылка / e-mail в тексте** | там же | Новая проверка → ошибка |

Решено владельцем 24.10.2026: хвастовство, символы/эмодзи, капс у владельца УЖЕ есть (`BANNED_CLAIMS` 2413, `bad_symbols` 3268, `shouty_words` 3276) — не дублировать.
Добавить только недостающее из `policy_issue()`: **«нажмите здесь» / click here** (языки как у коллеги `_CLICK_HERE`),
**телефон**, **ссылка/e-mail**, **повторы знаков («!!», «...», «…») и больше одного «!» в описаниях**.

## 3. Поток одиночной генерации (Search)

```
Старт: ключ (API) / Chrome+CDP (Браузер); URL или описание; ідентифікатор

1 ПОДГОТОВКА   build_request(): чистка описания, вариант из 800, wants (галочки), уточнения → user_text
               [API] THINK_LADDER по длине описания (новое)
2 ЧЕРНЕТКА     generate_draft(): API (MODEL_CHAIN) или browser_generate() (CDP)
               битый JSON → до 3 раз FIX_FORMAT_NOTE в тот же чат
3 ПЕРЕВІРКА    validate(): гео, язык, banned, ключи, заголовки, описания, расширения, числа, посадочная
               + телефон / ссылка в тексте (новое)
4 РЕМОНТ       build_repair_notes() → дослать в тот же чат → перепроверить; рецидивы и обрубки; до AUTO_ROUNDS_MAX
5 CSV          build_rows(): кампания, группы, ключи, объявления, расширения по галочкам,
               минус-слова = BUILTIN_NEG (новое) + от модели; write_csv() + free_path()
               «Кілька кампаній» → _many_worker, write_many_csv
```
Галочки (Callouts, Snippets, Sitelinks, Мінус-слова, Рандом) сильнее модели. Sitelinks по умолчанию выключены (якоря #1–#6 = обход систем Google).

## 4. Поток batch

```
ЗАГОТОВКА   canvas-таблица, Ctrl+V из Google Таблиц, F2, стрелки, Shift/Ctrl-клик, тянуть ширину колонки
            режим Профіль+Сайт / Профіль+Сайт+Опис (новое); автосохранение batch_table.json (есть)
            «Додати в чергу»
ЧЕРГА       статусы строк; _runner: генерация → проверка → ремонт → CSV

```

## 5. Состояния кампании

```
нова → генерується → чернетка → перевірка → чисто / помилки
     → [помилки] → ремонт → чисто / ще помилки → ручна правка → перевірка
     → [чисто] → CSV
```

## 6. Ошибки

| Что | Реакция |
|---|---|
| 429 | следующая модель цепочки |
| Дневной лимит | показать время сброса (полночь PT) |
| Битый JSON | до 3 раз FIX_FORMAT_NOTE |
| Рецидив / обрубок | жёсткая формулировка в repair notes |
| Chrome отвалился (CDP) | «Переоткрой Gemini» (reconnect — нет, вторая волна) |
| Файл существует | free_path → _2, _3 |
| Описание пустое после чистки игровой части | предупреждение, попросить описать разрешённую часть бизнеса |

## 7. Не берём / вторая волна

- Не берём: web UI коллеги, `parse_json_loose()`, `safe_error()`/SHA-256 (на усмотрение владельца).
- Вторая волна: reconnect CDP, тесты валидации (20–30 кейсов pytest без UI), бренды (Apple/iPhone — не ловит никто).
