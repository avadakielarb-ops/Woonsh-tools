# ПЕРЕНОС — пакет передачи проекта Woonsh Tools другому ИИ

Подготовлено 24.10.2026, ветка `claude/loving-bell-7hu4ks`.
Здесь собрано всё, что владелец обсудил и согласовал: концепция, логика, карта переноса кода, план, эталоны.
Исходный код лежит в репозитории на своих местах (`Фирмы/`, `ЦСВ Вайт/`, `X-File/`, `woonsh_tools/`) —
сюда не копируется, чтобы не было двух версий. Все пути в документах — от корня репозитория.

`CLAUDE.md` в этой папке — копия правил из корня репозитория.
`ВОПРОСЫ_ВЛАДЕЛЬЦУ.md` — вопросы и ответы владельца.
`ПРОВЕРКА_ДУБЛЕЙ.md` — где логика дублируется, что объединить, что нет.
`сценарий_заказа/` — путь заказа во всех вариантах + сквозной прогон на настоящем движке Фирм (`СЦЕНАРИЙ_ЗАКАЗА.md`, `ОТЧЁТ_ПРОГОНА.md`). Найдены 3 дыры в коде Фирм.
`ОТКУДА_ЧТО_БРАТЬ.md` — какой код откуда переносить и где у владельца лежат рабочие данные (реестр, книги, выписки, профили браузера).
