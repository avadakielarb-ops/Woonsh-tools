Загрузчик выписок

Загружает PDF-выписки на Google Drive, сопоставляет с компаниями и собирает Excel со ссылками. Всё через rclone — бесплатно и без API-ключей.

Первый запуск

1
Дважды кликни ІНСТРУКЦІЯ.bat — он проверит Python, установит библиотеки openpyxl и pypdf, покажет есть ли rclone.
2
Дважды кликни x-file.pyw — откроется окно программы.
3
Если rclone не найден — нажми в программе «Скачать rclone». Файл rclone.exe ляжет рядом с программой.
4
Если Drive ещё не подключён — используй Пакер архивов: там кнопка «Подключить Google Drive» → браузер → разрешить доступ. Remote gdrive общий для всех программ, подключается один раз.

Как пользоваться

Шаг 1. Профили → Excel

Вставь текст с платёжными профилями в верхнее поле. Формат — как из базы:

"C J ROOFING SERVICES LIMITED
1 Belvedere House Kingsway BISHOP AUCKLAND, England, DL14 7JN United Kingdom
http://www.roofingcountydurham.co.uk/"
"LIFE MAT SERVICES LTD.
BOSWORTH ACADEMY LEICESTER LANE DESFORD LEICESTER, LE9 9JL United Kingdom
http://www.bosworthacademy.org.uk/"

Жми «Распознать и создать Excel». Программа:

  • Вытащит названия компаний (строки с заглавными буквами)
  • Пропустит адреса и ссылки
  • Предложит сохранить .xlsx файл
  • Заполнит колонку A названиями. Колонка B пока пустая

Шаг 2. Папка с PDF → Сопоставление

Выбери папку с PDF-выписками кнопкой «Обзор», затем жми «Сопоставить файлы».

Программа пройдёт каждый PDF:

СитуацияЧто делает
Имя файла похоже на компанию Переименовывает точно под компанию → готов к заливке
Имя стандартное, не совпадает Открывает PDF, читает текст первой страницы, ищет название компании внутри, переименовывает
Ничего не совпало Покажет в логе как ✗ не опознан — переименуй руками
Совпадение нестрогое. Без регистра, без суффиксов LIMITED / LTD / PLC / SERVICES и т.д., по основным словам названия. Если в имени файла есть хотя бы ключевые слова компании — совпадёт.

Шаг 3. Загрузка → Ссылки в Excel

Вставь ссылку на папку Google Drive в поле «Ссылка на папку». Подходит полная ссылка или просто ID папки.

Жми «Загрузить и заполнить Excel». Программа:

  1. Загрузит всю папку на Drive через rclone
  2. Получит ID каждого файла на диске
  3. Соберёт ссылки вида drive.google.com/file/d/.../view
  4. Запишет ссылки в колонку B того же Excel

Компании без ссылки (не нашёлся файл) покажет отдельным списком в логе.

rclone и Google Drive. Remote gdrive общий с Пакером архивов. Если уже подключал Drive в Пакере — здесь ничего настраивать не надо. Если нет — один раз: в Пакере жми «Подключить Google Drive» → браузер → разрешить.

Чего не делать

  • Не менять вручную колонку A в Excel до загрузки — сопоставление идёт по этим именам
  • Не заливать в одну папку Drive выписки от разных партий — программа читает всю папку
  • Не удалять rclone.exe — без него загрузка не работает
